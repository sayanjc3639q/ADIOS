# ADIOS Hotel Management System
Planned enterprise suite module.

## Core Modules
- Room Booking & Interactive Calendar Matrix
- Guest Check-in / Check-out with ID Proof capture
- Restaurant / Room Service POS billing
- Housekeeping & Laundry schedules
- Banquet & Conference Hall reservations

Inherits UI, tabs, theme engine, and rolling SQLite backups from `packages/adios-core`.
